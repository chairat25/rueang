# Travel Wordlists — ข้อมูลสำหรับ `lib/travel/wordlists/`

> ไฟล์นี้เป็น **สเปกข้อมูล** ไม่ใช่โค้ด — ให้ transcribe ลง `lib/travel/wordlists/*.ts` ตามตรง
> ห้ามใส่ logic ในไฟล์ wordlist มีแต่ `export const ... = [...] as const;`

## กติกาการให้คะแนน

```
score = Σ (น้ำหนักของคำที่เจอ)   ← คำเดียวกันนับครั้งเดียว
shouldSuggest = score >= 4
```

**ทำไม 4:** ต้องเจอสัญญาณจากอย่างน้อย 2 กลุ่มถึงจะทัก — ป้องกันการทักมั่วซึ่งน่ารำคาญกว่าการไม่ทัก

| ข้อความ | คำที่เจอ | คะแนน | ผล |
|---|---|---|---|
| "ทริปเชียงใหม่" | ทริป(3) + เชียงใหม่(2) | 5 | ✅ ทัก |
| "ที่พักหัวหิน" | ที่พัก(2) + หัวหิน(2) | 4 | ✅ ทัก |
| "คาเฟ่ใกล้บ้าน" | คาเฟ่(2) | 2 | ❌ ไม่ทัก |
| "งานบ้านที่ต้องทำ" | — | 0 | ❌ ไม่ทัก |
| "จองโรงแรมญี่ปุ่น" | จอง(1) + โรงแรม(2) + ญี่ปุ่น(2) | 5 | ✅ ทัก |

**การจับคู่:** normalize เป็นตัวพิมพ์เล็ก ตัดช่องว่างซ้ำ แล้วเช็คแบบ substring
(ภาษาไทยไม่มีช่องว่างระหว่างคำ จึงใช้ word boundary ไม่ได้ — ใช้ `text.includes(term)`)
คำอังกฤษให้เช็คแบบ word boundary เพื่อไม่ให้ `trip` ไปแมตช์ `triple`
